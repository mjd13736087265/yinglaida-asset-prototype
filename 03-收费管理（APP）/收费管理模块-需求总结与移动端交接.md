## 一、模块定位

- 模块名称：**收费管理**（管理租金、押金、欠费、票据等资金类业务，不只租金）
- 本期只做**租金**主线；水电费为手工录入清单占位（M5 智能水电表上线后自动对接）；其他费用（卫生费/停车费/违约金）只列类型不展开

## 三、核心业务规则（拍板口径）

### 资金铁律
1. **先付后用**：账单按合同租期 + 付款周期提前生成（默认提前 15 天可配），过应收日未缴清即逾期；首期租金 + 押金为入住前置校验（默认开启可关）
2. **押金绝不允许抵租金**：押抵租、部分抵扣功能彻底删除，界面不出现任何相关内容（业主纪律，比纪要"保留不启用"更严格）
3. **不抹零**：少付差额只能 挂账（并入下期追缴）或 差额豁免（走审批留痕）；多付系统不自动处理，线下退回，账单上显示"多付 ¥X"标记
4. 账单状态机：待缴 → 支付中 → 已缴；另有 逾期、部分缴清（挂原账单，不生成新欠款单）

### 账单生成
- 按**合同约定的付款周期**（月/季/半年/年）滚动生成，以**合同租期起止时间**为依据（依赖合同模块，先做占位）
- 规则配置可切周期、设提前天数（默认 15 天）；保留手动生成单笔账单入口（月中入住补账）

### 核销（9·17 重构口径）
- 核销弹窗二选一：**部分核销**（本次金额从账单扣除，余额留账单 → 正常流程，无需审批）/ **全部核销**（账单结清；有差额时必选差额处理：挂账 / 差额豁免走审批）
- 核销时人工选择核销到哪笔账单（支持跨期合并付款）
- 收款登记字段：付款方式（转账/现金，在线走银联按钮）、转账信息（户名/账号/开户行/时间/凭证，凭证非必填）、**收款账户**（默认读合同账户，可下拉多选切换，数据源来自片区管理模块）、**经办人**、备注
- 匹配规则：金额 → 付款人姓名 → 房号 依次模糊匹配，匹不上留人工，绝不自动销账；银联自动核销 + 人工通道永久并存

### 二维码与支付
- **代付**（账单管理）：账单级银联收款码，弹窗确认账单信息 → 出码 → 扫码支付**自动核销**；码可截图转发兼作催款单；有效期占位 30 分钟（待银行确认），未过期不重复生成
- **付款码**（收款核销）：账单级银联收款码，**管理员可选支付金额（≤ 账单金额）**，支持现场部分支付，支付即核销
- **通用小程序码**（扫码直达小程序账单页）：放**导航栏**，随时查看 / 下载 / 转发
- 退款：银联不支持超一年原路退回、不支持部分退款——退款流程留待下次会议讨论

### 票据（9·17 定稿）
- **收据**：申请制（不自动生成），用户端/管理端均可发起，**发起即给客户，无审批**；默认全额可改金额；编号 SJ+片区编号+年份+流水（已确认）；A5 一联打印；模板在现有设计基础上补：备注栏、经办人/收款人、租期起止日期、租房位置（与合同一致）、收款事由、金额大小写、收款专用章自动带出、单片区多抬头（系统管理配置，先占位）
- **发票**：白名单制（无权限用户看不到入口）；双路径——用户端发起→审批人审批→财务上传→发送用户；管理端（审批人）代发起→**免审批**→财务上传→发送用户；财务有独立上传页（可修改、作废冲红重开）；上传完成自动短信通知（含 PDF 链接）
- **可申请金额** = 账单金额 − 已开票 − 已开收据，用户在同一账单内自由分配发票/收据金额，累计 ≤ 账单金额
- 账单列表"票据状态"列分两维：开具程度（未开具/部分开具/已开齐）× 类型（发票 ¥X · 收据 ¥Y），点开看明细
- **用户端不出现"发票"字样，统一命名"凭证申请"**

### 欠费与催缴
- 台账：欠费总额、欠费用户数、逾期 30 天以上提醒、按逾期天数从多到少排序、按费用类型筛选
- 催缴：单个/批量（显示已选 X 人），话术模板按严重程度分级，**通知渠道只有两种：系统内部通知 + 短信**（无小程序服务通知），阶梯规则自由增删、天数与话术均可配；每人留完整催缴记录
- **线上断水断电不做**（法律风险），统一线下处理；断水断电入口删除

### 押金
- 独立台账（业主反复强调）：在押总额/本月收取/本月退还；按租户搜索；押金标准、实收余额、流水、退还记录
- 收退正常由业务流程自动产生，仅保留"收取登记/退还登记"两个手动入口；退还与退租流程联动（退租模块后续）
- 异常退房：退住时触发，本模块预留，退租模块两头可用

### 特殊处理
- TAB 分页：部分核销（差额豁免）/ 挂账 / 坏账 / 异常退房；押抵租已删
- 坏账：人工逐笔转 + 可平账归档（归档后记录保留可追溯，不再明面提醒）

### 通用
- **所有列表页底部加数据总计行**（9·11 跟进 25）
- 账单管理列表分 TAB：**已缴**单独一个 TAB，**待付**装其他全部状态（待缴/支付中/逾期/部分缴清）
- 时间筛选组件：全部 / 本年 / 本月 / 自定义日期

## 四、移动端需求要点（本文件服务对象）

### 移动管理端（小程序，管理员用）
- 底部 Tab 用共享 `m-tab.js`，开工时按规范 §7 解锁 rent Tab
- 规划页面：移动收费工作台（今日收款/待核销/欠费概况）、账单列表+详情、收款核销（待核销列表、收款登记、部分/全部核销弹窗）、欠费列表+催缴、押金台账
- 与 PC 端功能一致，仅展示形式适配手机（片区管理已定此原则）；片区切换沿用顶部切换
- 现场场景重点：付款码（选金额部分支付）、收款登记、催缴

### 用户端（小程序，租户用）
- 账单分**待缴 / 已缴**两个清单（已缴多少、剩余多少一目了然）
- 在线支付走银联（支付按钮占位，对接中）
- **凭证申请**入口（不叫发票）：可申请收据或发票，同一账单内分配金额，实时显示可申请余额；发票仅白名单用户可见
- 发票开具后短信 + PDF 链接下载；收据申请后直接推送
- 保持简洁：我的房源、待缴账单、凭证申请、在线报修、水电查询（后两项后续模块）
